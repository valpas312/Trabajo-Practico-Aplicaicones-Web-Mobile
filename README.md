# Elegi la opcion de app de tareas con recordatorio

## Para ejecutar el proyecto, sigue estos pasos:
1. Clona el repositorio en tu máquina local.
2. Abre el proyecto en tu entorno de desarrollo preferido.
3. Asegúrate de tener las dependencias necesarias instaladas.
4. Ejecuta el proyecto para ver la aplicación de tareas con recordatorio en acción.

## Funcionalidades principales
- Crear tareas con título, descripción y fecha de vencimiento.
- Establecer recordatorios para cada tarea.
- Marcar tareas como completadas.
- Visualizar una lista de tareas pendientes y completadas.
- Editar y eliminar tareas según sea necesario.
- Recibir notificaciones de recordatorio en la fecha y hora establecida.
